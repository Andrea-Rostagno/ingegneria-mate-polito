# Idrolisi salina

> Gli ioni di un sale che sono base o acido coniugato di specie deboli reagiscono con l'acqua e rendono la soluzione basica o acida.

## Definizione / enunciato
Un sale in acqua si dissocia completamente; se uno dei suoi ioni è la base coniugata di un acido debole o l'acido coniugato di una base debole, reagisce con l'acqua (**idrolisi**) e cambia il pH.
- **Acido forte + base forte** (NaCl): nessuna idrolisi, pH = 7.
- **Acido debole + base forte** ($\mathrm{CH_3COONa}$, KCN, $\mathrm{KNO_2}$): l'anione è una base di Brønsted, $\mathrm{A^-+H_2O\rightleftharpoons HA+OH^-}$; idrolisi basica, pH > 7, tanto più quanto più debole è l'acido e più concentrato il sale.
- **Acido forte + base debole** ($\mathrm{NH_4Cl}$): il catione cede $\mathrm{H^+}$; idrolisi acida, pH < 7.
- **Acido debole + base debole** ($\mathrm{NH_4NO_2}$, $\mathrm{CH_3COONH_4}$, $\mathrm{NH_4CN}$): si idrolizzano entrambi; se $K_b$(anione) > $K_a$(catione) la soluzione è basica, se minore acida, se uguali neutra.

## Formule chiave
$$\mathrm{A^-+H_2O\rightleftharpoons HA+OH^-},\qquad K_b(\mathrm{A^-})=\frac{K_w}{K_a(\mathrm{HA})}$$

## Intuizione
Il "sale neutro" è neutro solo se nessuno dei suoi ioni ha carattere acido o basico apprezzabile: l'anione di un acido debole è una base abbastanza forte da strappare protoni all'acqua.

## Come si usa
Una soluzione di acetato di sodio è basica: $\mathrm{CH_3COO^-+H_2O\rightleftharpoons CH_3COOH+OH^-}$ (p. 47). Al punto di equivalenza della titolazione di un acido debole con una base forte la soluzione contiene il sale e quindi ha pH > 7.
